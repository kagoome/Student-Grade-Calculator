
# Student Grade Calculator

Aplikasi kalkulator nilai akademik berbasis Flutter yang memungkinkan pengguna menghitung nilai akhir berdasarkan komponen penilaian dan sistem konversi nilai yang dapat dikustomisasi.

## Features

- Menambahkan komponen penilaian secara fleksibel.
- Mengatur bobot setiap komponen.
- Menghitung nilai akhir secara otomatis.
- Menggunakan Original Template atau Custom Grade Template.
- Membuat, mengedit, menduplikasi, dan menghapus template nilai.
- Menampilkan hasil perhitungan akademik.

## Tech Stack

- Flutter
- Dart
- Shared Preferences

## Installation
